## Задание: два адаптера вентилятора

Практика со слайда 19 презентации «Лекция 3». Номер — фактический порядок слайда в файле.
Работайте в [devices.py](devices.py). Примеры адаптеров лампы уже реализованы.

Готовый `ForeignFan` имеет метод `set_mode("RUN")` / `set_mode("STOP")`.
Клиент ожидает `Switchable.set_power(enabled)`.

1. Добавьте `FanAdapter(Switchable)` — адаптер объекта. Конструктор принимает
   готовый `ForeignFan` и сохраняет именно этот экземпляр в `self.fan`.
   `set_power(True)` вызывает `self.fan.set_mode("RUN")`,
   `set_power(False)` — `self.fan.set_mode("STOP")`.
2. Добавьте `FanClassAdapter(Switchable, ForeignFan)` — адаптер класса.
   Конструктор без аргументов инициализирует унаследованный `ForeignFan`;
   начальный `mode` равен `"STOP"`. `set_power()` вызывает унаследованный
   `self.set_mode()` с теми же значениями. Старый метод остаётся доступен.
3. Проверьте оба адаптера в одном списке с `ModernLight`, `LampObjectAdapter`
   и `LampClassAdapter`. Весь список управляется неизменённым `set_all_power()`.
   Повторные команды включения и выключения также должны работать.

Не меняйте `ForeignFan`, `Switchable`, `set_all_power()` и тесты.
Не присваивайте `mode` напрямую: используйте готовый API вентилятора.
После добавления классов демонстрация автоматически покажет оба вентилятора.

## Проверка задания

Из этой папки паттерна:

```bash
pytest tests/test_task.py
```

Пока классы не добавлены, проверки дают `FAILED` с подсказкой. Задание выполнено,
когда все пять тестов завершаются `PASSED`, без пропусков. Тесты проверяют сохранение
исходного объекта, наследование, начальное состояние, вызовы стороннего API
и работу обоих адаптеров через общий клиент.
