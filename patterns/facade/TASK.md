## Задание

Практика со слайда 29 презентации «Лекция 3». Номера слайдов здесь и в README — фактический порядок в файле.


Добавьте **в класс `HomeFacade`** метод `leave_home()` — сценарий «Ушёл из дома».
После вызова:

- яркость освещения равна 0;
- шторы закрыты;
- проектор выключен, источник сброшен в `None`;
- звук выключен, громкость равна 0.

Используйте публичные методы подсистем, не присваивайте их полям значения напрямую.
Метод должен работать и сразу после создания дома, и после `start_movie()`.
Повторный вызов должен сохранять то же состояние.

Демо вызовет новый сценарий после добавления метода.


## Проверка задания

Откройте терминал в этой папке паттерна и выполните:

```bash
pytest tests/test_task.py
```

Пока требуемые классы, метод или функция не добавлены, тесты завершаются `FAILED` с подсказкой.
Задание выполнено, когда все проверки завершаются `PASSED`, без пропусков. Тесты менять нельзя.
Работающий пример отдельно проверяется командой `pytest tests/test_example.py`.
