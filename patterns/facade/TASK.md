# Задание

Добавьте **в класс `HomeFacade`** метод `leave_home()` — сценарий «Ушёл из дома».
После вызова:

- яркость освещения равна 0;
- шторы закрыты;
- проектор выключен, источник сброшен в `None`;
- звук выключен, громкость равна 0.

Используйте публичные методы подсистем, не присваивайте их полям значения напрямую.
Метод должен работать и сразу после создания дома, и после `start_movie()`.
Повторный вызов должен сохранять то же состояние.

Не меняйте тесты. Из этой папки запустите проверку — все тесты должны пройти:

```bash
pytest tests/test_task.py
```
