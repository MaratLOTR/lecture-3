# Facade — Фасад

Пример: слайды 22–27; задание: слайд 29 презентации «Лекция 3».

## Проблема

Чтобы посмотреть фильм, клиент должен закрыть шторы, приглушить свет,
включить проектор с правильным источником и настроить звук. Без фасада
каждый клиент повторяет последовательность и знает интерфейсы четырёх подсистем:

```python
curtains.close()
lighting.set_brightness(20)
projector.turn_on("HDMI 1")
sound.turn_on(35)
```

## Решение и роли

`HomeFacade.start_movie()` выражает намерение пользователя одним вызовом.
Метод `end_movie()` выключает проектор и звук, возвращает яркость 100% и открывает шторы.
Он устанавливает заранее определённое состояние, а не восстанавливает произвольные прежние настройки.

| Роль | Участник |
|---|---|
| Facade — высокоуровневый интерфейс | `HomeFacade` |
| Подсистемы | `Lighting`, `Curtains`, `Projector`, `SoundSystem` |
| Client | код демонстрации, вызывающий `home.start_movie()` |

```text
Клиент → HomeFacade.start_movie()
           ├─ Curtains.close()
           ├─ Lighting.set_brightness(20)
           ├─ Projector.turn_on("HDMI 1")
           └─ SoundSystem.turn_on(35)
```

Фасад получает экземпляры подсистем через конструктор. Подсистемы не знают о фасаде;
их по-прежнему можно использовать напрямую для нестандартных сценариев.

## Код и запуск

- [home.py](home.py) — четыре подсистемы и фасад.
- [__main__.py](__main__.py) — начало и завершение просмотра фильма.

Нужен Python 3.10+ и pytest 9+. В Codespaces pytest устанавливается автоматически.
Из этой папки паттерна (её можно передать студенту отдельно):

```bash
python3 __main__.py
pytest tests/test_example.py
pytest tests/test_task.py
```

`test_example.py` проверяет готовый пример, `test_task.py` — выполнение задания.
До выполнения задания вторая проверка выдаёт ошибки; это ожидаемо.

## Применимость и ограничения

Фасад полезен, когда клиентам нужен небольшой набор типовых операций сложной подсистемы.
Он уменьшает число зависимостей клиента и собирает порядок действий в одном месте.
Если включить в него все возможные сценарии, класс может стать слишком большим.
Фасад сам по себе не обеспечивает откат при сбое одной из подсистем.
