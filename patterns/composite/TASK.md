## Задание

Практика со слайда 43 презентации «Лекция 3». Номера слайдов здесь и в README — фактический порядок в файле.


Добавьте в `tree.py` функцию `build_demo_house() -> DeviceGroup`, которая создаёт
и возвращает такое дерево:

```text
Дом (DeviceGroup)
└── Первый этаж (DeviceGroup)
    ├── Гостиная (DeviceGroup)
    │   ├── Лампа (Device)
    │   └── Телевизор (Device)
    └── Кухня (DeviceGroup)
        └── Чайник (Device)
```

1. Названия и порядок детей должны совпадать со схемой.
2. Дом, этаж и комнаты — `DeviceGroup`; приборы — `Device`.
3. Все приборы изначально выключены.
4. Каждый вызов создаёт новые объекты: два дома не должны делить одни устройства.
5. Собирайте дерево через `add()`, не изменяйте `_children` напрямую.

Проверьте включение всего дома, выключение только гостиной и выключение всего дома.
После добавления функции демо дополнительно покажет ваше дерево.


## Проверка задания

Откройте терминал в этой папке паттерна и выполните:

```bash
pytest tests/test_task.py
```

Пока требуемые классы, метод или функция не добавлены, тесты завершаются `FAILED` с подсказкой.
Задание выполнено, когда все проверки завершаются `PASSED`, без пропусков. Тесты менять нельзя.
Работающий пример отдельно проверяется командой `pytest tests/test_example.py`.
